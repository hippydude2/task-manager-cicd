## Task Manager Documentation

This project is a Python-based task management system.

It uses automated unit testing to verify task functionality.

GitHub Actions and Docker are used to automate the CI/CD pipeline.

The pipeline runs the Python application, executes unit tests,
and updates index.html with the results.

## Task Manager
